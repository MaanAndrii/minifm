## I2S state and larger clock

The project overrides the codec I2S source through CMake with main/vendor/audio_codec_data_i2s.c, preserving the upstream Apache-2.0 header. This board-specific driver initializes physical RX/TX state from the Waveshare BSP contract (both allocated channels are enabled before interface creation). State changes only after a successful driver transition; redundant enable/disable calls are skipped. scripts/test_i2s_state.py tests the actual helper with mocked channel operations, including retries after failures. Managed dependencies remain untouched.

The clock page uses a 160 px numeric font, a 456 px label and a wider station footer at a reduced bottom margin. Other numeric pages retain 96 px. The panel and partial DMA buffer remain 480x480 and 15360 bytes. The LVGL harness checks representative clock strings fit without clipping. Firmware builds successfully; physical audio and display validation remains pending.
